# Fight Empire

A boxing promoter/management simulation. Build a tiny promotion into a global boxing empire.

**Status: Phase 1 (Foundation).** See [docs/ROADMAP.md](docs/ROADMAP.md) for what is and isn't playable yet
and [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for how it is built.

```bash
npm install
npm run dev        # play at http://localhost:5173
npm test           # engine tests (Vitest)
npm run build      # typecheck + production build
```
